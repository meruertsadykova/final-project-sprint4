# Selenium JUnit4 Automation Project

## 📌 Project Overview
This project is an automated UI testing suite built using **Java**, **Selenium WebDriver**, and **JUnit 4**. It is designed to run functional tests against a web application.

## 🛠️ Technologies Used

| Technology            | Version |
|-----------------------|---------|
| Java                  | 11      |
| JUnit                 | 4.13.2  |
| Maven                 | 4.0.0   |
| Selenium WebDriver    | 4.17.0  |
| SLF4J                 | 2.0.12  |
| Logback Classic       | 1.5.16  |
| Maven Surefire Plugin | 3.2.5   |

## ⚙️ Setup Instructions

1. Make sure you have **Java 11+** and **Maven 4.0.0** installed.
2. Clone this repository:
   ```bash
   git clone https://github.com/meruertsadykova/final-project-sprint4
   cd final-project-sprint4

3. To run the test suite, execute
   ```bash
   mvn clean test
